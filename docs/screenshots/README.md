# 游戏截图

拍摄日期：2026-10-31。游戏版本：`0.39-bloodstrike-team-rounds`。

图片来自完整资源环境的浏览器运行画面。桌面视口为 1440 × 900，手机横屏视口为 844 × 390。发布图片只做 WebP 压缩，没有替换画面内容；手机图展示浏览器触屏布局，不代表实体设备性能测试。

| 图片 | 内容与拍摄方式 |
| --- | --- |
| [desert-rifle.webp](desert-rifle.webp) | 沙漠旧城、AK-47 与机器人小队；内置 `capture=active-play&weapon=rifle` 场景定格。 |
| [dust2.webp](dust2.webp) | Dust2 地图；内置 `capture=menu&preview=map&map=dust2` 场景展示。 |
| [snow-awp.webp](snow-awp.webp) | 雪地竞技场与 AWP；内置 `capture=active-play&map=snow&weapon=sniper` 场景定格。 |
| [knife-grip.webp](knife-grip.webp) | 最新经典匕首与双手握持；内置 `capture=active-play&weapon=knife` 场景定格。 |
| [supply-shop.webp](supply-shop.webp) | 沙漠旧城正常开局后打开补给商店，显示武器图片、价格与购买快捷键。 |
| [mobile-bloodstrike.webp](mobile-bloodstrike.webp) | Bloodstrike 正常进入赏金回合后的首局手枪开局；`touch=1` 启用触屏布局。 |

场景定格参数需要 `debug=1`；截图时使用游戏已有的截图入口隐藏开发面板。直接游玩请使用 [正式入口](https://ihca.cn/sandline/)。

截图展示的第三方模型、地图与贴图仍适用其原有许可，参见 [NOTICE.md](../../NOTICE.md)。截图展示不改变这些素材的再分发授权。
