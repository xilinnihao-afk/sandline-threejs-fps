# 机器人小队战术（2026-10-21）

本次针对沙线行动的步兵机器人。玩家面对会分工、接近、换位和隐蔽的小队；战斗强度来自行动选择。现有伤害、枪械散布、有限弹药、反应延迟与视线遮挡继续适用。决战中途岛的飞行 AI 不在本次范围。

## 行为与实现

- `botCombat.ts`：在现有优先级控制器中加入小型效用选择器。当前可开火的队员担任掩护，其余按槽位分为突击及左右侧翼；换弹、低生命、离开接触的队员不承担掩护。人类玩家必须实际开火才被计入火力掩护；自动测试驱动玩家角色时使用机器人规则。个人军备竞赛不共享战术。
- `botTactics.ts`：参考 EQS 的“候选点→过滤→评分”流程。候选来自平面掩体边角或 Dust II 原始导航点；验证身体可通行、路径长度、头肩遮挡、威胁高度、武器距离、路线中途暴露及队友占位。目的地短期预约防止抢位。已在安全位置时原地换弹。
- `simulation.ts`：局部队友情报、延迟约 0.2 秒且 2.5 秒过期的近似报点、短距离火力压制、武器射程驱动推进、可见敌人换弹时接近、队友交替战术换弹、有限掩蔽停留后重新接敌、接近旧接触点时蹲行。紧迫拆弹/据点推进保持任务优先。
- 全量感知约 8–10 Hz，战术选择约 1.2–1.8 Hz，移动和瞄准仍跟随模拟帧。两次感知之间持续检查已选目标的真实视线，开火前再验证遮挡和友军；被墙遮住后不会继续更新隐藏位置。高成本 BSP 寻路只检查前三个候选。
- 子弹掠过身体 1.15 米以内会积累短期压力，仅考虑真实飞行到达的线段和无遮挡听觉刺激；不会改变武器伤害或准度。掩蔽有到达期限及有限停留，过期或换弹完成后可再次接敌。

## 玩法约束

正常循环：发现/收到报点 → 保持一个火力点 → 队友接近或侧移 → 停步点射 → 受压、换弹时隐蔽 → 重新选择角度。缺乏可靠接触时执行原有巡逻和目标，不访问隐藏敌人的实时坐标。小队分工是局部合作，地图不同区域可各自形成火力组，不承诺固定全队只有一个掩护手。

改变策略会改变随机数消耗和对局结果。种子回归因此要求每局双方实际命中、整组双方有击杀、目标可完成及无穿墙，不要求任意指定种子都必须避免零击杀败局。
