# 分阶段轻量爆炸模块

文件：`src/render/explosionSystem.ts`。`CombatEffects` 的 `explosion` 与 `bombExplode` 事件使用此模块，不改变伤害、引爆或计分。

```ts
const explosions = new ExplosionSystem({
  duration: 1,          // 冲击时间倍率（0.5–1.5），不延长残烟
  smokeDuration: 2.8,   // 手雷残烟秒数（1.5–5），炸弹为此值的 1.4 倍
  scale: 1.8,          // 手雷空间倍率；炸弹另外放大 1.35 倍
  lightIntensity: 330,
  lightDistance: 12,
  shakeStrength: .14, // 总相机位移上限，设 0 禁用
  shakeRadius: 18,
  maxConcurrent: 2,   // 硬上限 2
});
scene.add(explosions.root);
explosions.spawn(position, occluded, 'grenade'); // 炸弹第三参传 'bomb'

// 每帧先重建基础相机位置，再加当前帧偏移，避免累积漂移。
updateFPSController(dt);
explosions.update(dt, camera);
camera.position.add(explosions.getShakeOffset(camera, shake));

explosions.reset();   // 回合重开：清活跃效果，保留固定资源池
explosions.dispose(); // 离开关卡：释放所有自有 GPU 资源，只释放一次
```

## 视觉层与独立时间

默认冲击倍率为 1 时：

| 层 | 数量 | 时间与用途 |
| --- | ---: | --- |
| 核心闪光 | 1 | 85ms 内急速扩张衰减，建立引爆瞬间 |
| 翻卷火焰 | 6 | 错峰出现，约 0.57s 全部结束；朝外扩张再卷起 |
| 柔边压力尘环 | 1 | 0.45s；噪声孔隙、软边，避免硬实心圆环 |
| 贴地尘浪 | 4 | 约 0.99s；快速径向扩散，压扁形状 |
| 升腾残烟 | 8 | 手雷 2.8s、炸弹 3.92s；错峰升腾扩张，缓慢散去 |
| 火星/碎片 | 18 | 12 火星、6 碎片，一次实例绘制，0.85s 内结束 |

每次 38 元素，最多 76；两盏短期点光。所有可见材质启用深度测试、关闭深度写入。火焰使用加法混合，烟与尘使用普通透明混合。烟团透明度上限为 0.72，维持至单团寿命 42% 后再平滑淡出。烟采用独立的 64×64 饱满软边纹理与深灰褐烟核，纹理平均 alpha 为 0.2399、单图层实际 alpha 上限为 0.6466。缩放前上升速度为 0.32–0.55 米/秒，避免迅速升散后在明亮地面上失去辨识度；火焰仍用原本较疏松的纹理。

灯光在 0.2s 内指数衰减；震动 0.42s 后严格归零。炸弹放大空间尺度与瞬时亮度，延长残烟；不会将火焰、碎片、冲击与相机震动一并放慢。

## 资源、遮挡与边界

初始化时建最多两套可复用对象、两份共享几何体、四张共享 64×64 纹理。连续引爆、过期、回合重开都复用这些 GPU 资源；超预算时回收最旧效果。`dispose()` 释放实例缓冲、共享几何体、材质、纹理及灯光。Three.js 内部共享的 Sprite 几何体不由本模块释放。

`occluded` 应由事件源到观察者的真实视线检测提供，手雷和炸弹均须计算。受遮挡时不点亮局部灯光，震动降为 30%，可见图层由场景深度遮挡。局部点光不投射阴影：这样避免移动端六面动态阴影尖峰，但可见事件的点光不具备完整的任意墙面物理遮挡。碎片和烟尘为表现层，不参加物理碰撞或伤害计算。

`diagnostics()` 提供活跃槽、元素预算、实际亮灯数、池容量、残烟阶段数量及独立寿命。`tests/explosionEffects.test.ts` 验证连续引爆复用、完整释放、独立寿命、震动复位、遮挡关灯、材质深度测试、烟纹理覆盖率和帧率一致性。
