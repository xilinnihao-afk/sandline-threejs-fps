# 沙线行动 v0.10 — 游戏设计与迭代入口

## 游戏承诺

在手机上持续进行第一人称掩体交火：认清路线、停步瞄准、控制点射，在蓝红两队交火中提高个人击杀排名。节奏参考经典 CS 1.6；v0.2 用骨骼人物、做旧建筑与本地采样音效增强空间感，使用原创地图结构与有许可的第三方资产。

当前默认玩法为持续团队对战，两张地图均使用击杀排名，无局数、时长或击杀上限。默认玩家与 2 名蓝方机器人对抗 3 名红方机器人，菜单可配置到 5 对 5。按个人击杀数降序、死亡数升序排名，完全相同则并列；队伍分数显示累计击杀。阵亡后观察队友，3 秒后自动复活，保留枪械、金钱和统计并补满弹药；1.5 秒保护在开火或投雷时结束。复活选择避开敌人视线与存活角色的出生点。重新开始清空本场排名。旧爆破/歼灭规则仅保留在模拟器兼容测试中。

## 5–30 秒核心循环

1. **观察与选路**：离开掩体，读取队友位置、剩余人数和交火方向。
2. **接敌**：绕过墙角或木箱，短距离移动后停步，必要时蹲伏降低散布。
3. **交换火力**：点射、切换近战武器或投掷手雷；利用命中标记、弹道和声音决定压制还是退回掩体。
4. **重整推进**：在安全位置换弹或改走侧路，减少敌方人数并形成下一次推进机会。

交火没有强制脚本时长。100 点生命、有限弹药、装填锁定、移动与连射散布构成压力；绕侧路和寻找掩体换弹比站桩更安全。成功获得击杀排名与 +$300；阵亡记一次死亡并扣 $200，随后快速重返战斗。HUD 显示自身名次、领先者、团队累计击杀和已进行时间。查看完整排行榜会暂停游戏。两端地面武器每 20 秒补充，掉落武器有时效和数量上限，避免长时间对战无补给或持续积累模型。

## 地图：沙漠仓储旧区

44 × 40 米场地，蓝方南侧出生、红方北侧出生，两栋仓储建筑形成三条相连路线：

| 路线 | 战术作用 |
| --- | --- |
| 中央货场 | 直接南北连接，木箱切分长视线，适合转移和正面接敌。 |
| 西侧绕行 | 绕过建筑与集装箱，用于侧击和避开中央交火。 |
| 东侧绕行 | 另一条外围选择，箱体提供局部遮挡，连接入口及出生区。 |

所有主要碰撞体来自 `MAP_BOXES`，渲染和导航共享布局。建筑门窗关闭，不含可进入楼层或可登上屋顶。v0.2 加入石板地、灰泥/砂岩墙面、木门窗、拱石、线缆、空调、遮棚与远景屋顶；装饰布置在墙面、高处或地面，不把新障碍放入通行路线。

## 武器、手雷与机器人

| 武器 | 弹匣 / 备用 | 射击间隔 | 换弹 | 身体 / 头部伤害 |
| --- | --- | --- | --- | --- |
| AK 系步枪 | 30 / 90 | 0.115 秒 | 2.15 秒 | 27 / 84 |
| USP 手枪 | 12 / 48 | 0.29 秒 | 1.45 秒 | 24 / 66 |
| MP 系冲锋枪 | 30 / 120 | 0.075 秒 | 1.9 秒 | 17 / 48 |
| 泵动霰弹枪 | 8 / 32 | 0.88 秒 | 3.1 秒 | 每弹丸 12 / 22，共 8 枚并有距离衰减 |

射线取墙体与角色头身包围盒的最近交点；友军不会受伤，但阻挡射线。蹲伏降低速度、视点和散布；辅助瞄准提供可关闭的小范围横向修正。换弹期间不能射击或切枪；霰弹枪使用定时补满规则，装壳动画是表现层简化。

每人每次复活赠送 1 枚手雷，2.15 秒引信、6 米范围伤害，按距离衰减且受墙体遮挡；投掷者可能自伤，其他友军免伤。轨迹由重力及球/AABB 子步反弹更新。投掷、触地和爆炸驱动声音、烟尘、火花与镜头反馈。

机器人保留视野、视线遮挡和反应延迟，只使用亲眼可见目标、最近观察位置、近处枪声/跑步声与短期队友报告。路线经过带身体宽度检查的平滑处理，到达后才轮换巡逻点；每人有独立移动速度、反应和停顿。交战时会承诺一次侧向换位、停步点射，受伤或装填时选择可达掩体；空弹近身切手枪，全武器弹尽时前往地面补给。近处可见手雷触发躲避。保持有限信息与有误差的瞄准，不增加伤害或穿墙感知。

## 人物、枪械与声音

角色来自 Mixamo Vanguard / Three.js Soldier，49 个皮肤关节，使用 Idle、Walk、Run 片段。表现层叠加持枪上身 IK、瞄准、后坐、蹲伏及渐进倒地；队伍用制服材质色区分。当前是一套基础角色，不含专门的侧移动作、脚底锁定或物理布娃娃。

四枪第一/第三人称造型拥有独立弹匣、枪机或泵动部件，握持点跟随手部骨骼。第一人称换弹展示取匣、插入、拍实、拉栓及复位；手臂仍为程序建模的风格化外观。

24 个本地 WAV 覆盖四枪、爆炸、机械换弹、脚步、撞击、环境与界面。Web Audio 在用户手势中解锁，按距离、方向混音，设置可试听与静音；暂停清理活动及排期音源，恢复只保留一条环境循环。音频诊断读取真实 AudioContext 和总音量之后的波形。

## 操作与界面

横屏左手摇杆、右侧滑动瞄准、独立开火按钮支持按住和拖动。换弹、切枪、手雷、蹲伏至少 50 CSS 像素；暂停 48 像素，开火 88 像素（小屏缩小）。比分、时间与人数居顶，生命和弹药分居底部两侧。

桌面使用 WASD、鼠标、R、1/2/3/4、G、C、Esc。页面隐藏或失焦时清理输入并暂停，恢复由玩家触发。设置保存在本地，对局没有断点存档。

## 工程决策

| 决策 | 实现与理由 |
| --- | --- |
| 模拟与表现分离 | Simulation 管规则，Three.js 读快照和事件；骨骼、粒子和声音不决定命中。 |
| 固定 60 Hz | 限制后台补帧；一次性输入保留至模拟消费，避免高刷丢失投掷操作。 |
| 自定义碰撞 | 二维圆形角色、地图 AABB、三维 hitscan；少量球形手雷采用子步碰撞，无需整套物理引擎。 |
| 共享资源 | 环境合并为 14 个材质批次；角色共享几何/纹理，复制骨骼；特效池复用对象。 |
| 阴影分档 | 低画质以简化建筑代理投影，角色保留阴影；高画质使用详细建筑投影；持枪模型不投昂贵阴影。 |
| 本地资源与许可 | 模型、纹理、声音随 public 分发；外部生成凭证缺失，采用许可下载及本地处理，保留署名。 |
| 可复现验证 | 固定种子测试规则与完整对局；实际浏览器手势、动作序列、音频分析及画布像素诊断分别留证。 |
| 静态与离线 | Vite 输出 dist，构建生成版本化预缓存；手机安装须 HTTPS，局域网 HTTP 供试玩。 |

本轮使用 threejs-game-director 及玩法、画面、UI、音频、资产与 QA 技能；详情与实际验证边界见 [最终验收](../artifacts/final-evidence.md)。移动目标预算为 150 calls、300,000 三角形、200 几何资源、40 纹理；桌面 GPU 数字不能代替手机性能。
