# Showcase scope and credits

This repository is a public showcase for SANDLINE. It contains English documentation and screenshots, plus a link to the hosted browser game. It is not an open-source release of the game implementation.

Game source code, models, textures, audio, and deployment files are not included. Some model and voice assets do not yet have sufficiently documented standalone redistribution terms for a source-and-assets release. Access to the live demo does not grant permission to extract or redistribute its assets.

The game uses Three.js, TypeScript, Vite, and Rapier. Project asset records include:

- Mixamo / Three.js Soldier reference animations.
- Poly Haven environmental textures (CC0).
- Michel Baradari / OpenGameArt gun and explosion sounds (CC BY 3.0).
- SpringySpringo / OpenGameArt reload recordings (CC0).
- Synthesized Mandarin voice callouts generated with the macOS Reed voice.

These acknowledgments describe the demo's dependencies and recorded asset sources; they do not relicense any third-party material. The live game's asset credit pages provide additional attribution:
